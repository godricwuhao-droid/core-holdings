# 「资产 / 库存」字样全盘检查清单（含修改建议）

> 日期：2026-10-19
> 状态：**已于 2026-10-19 按本清单执行完毕**（3 个决策点按建议值落地：平台名「蜂云产品及服务平台」、具身智能/算力服务加「产品及服务」后缀、历史日志不回溯；
> 「资产总数」实际统一为「产品总数」，与清单建议的「总数量」等义且全端一致）。前后端 + 存量数据残留检索归零，构建/编译/健康检查通过。
> 原始检查口径（执行前快照）：
> 背景：平台是对外产品平台，视角从内部「资产/库存」切换为面向客户的「产品及服务」：
> 内部视角的"资产"调整为面向客户的"产品及服务"分类——"卫星产品及服务"、"软件产品及服务"、"硬件产品"，
> 通过清晰的板块划分让客户直观识别哪些是产品、哪些是服务。
>
> 统计口径：**用户可见**内容（菜单/标题/列头/按钮/弹窗/提示/placeholder/空态/tag/日志文案/报错消息/种子数据）。
> 代码注释、变量名、类型名、CSS、路由路径、API 路径**不在清单内**（不影响用户）。
>
> 「建议修改后」列为基于上述口径推导的建议值，⚠️ 标注处为需拍板项。
