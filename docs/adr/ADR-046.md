# ADR-046: 引入官方品牌 Logo（蜂云时代蜂鸟）替换占位图形

## Status
Accepted

## Context
`/root/fengyun-web/public/brand/` 提供了官方品牌素材：
- `logo-icon.png`：绿色蜂鸟 + 轨道环图形（透明底图标）
- `logo-dark.png`：横向完整 logo（图标 +「蜂云时代」黑色字标，适合浅底）
- `images/logo.svg`：144×40 横向完整 logo 的 SVG 版本

当前平台使用自绘蓝色占位图形（`favicon.svg` 准星圆），MainLayout 顶栏与登录页
logo 均为 Element Plus `Coin` 图标 / favicon.svg，与真实品牌不一致。

## Decision
1. 将 `logo-icon.png`、`logo-dark.png`、`logo.svg` 复制到
   `frontend/public/brand/`，由静态服务直接引用。
2. **MainLayout 顶栏**：`Coin` 图标 → `logo-icon.png`（高度 ~26px）+ 保留
   「蜂云产品及服务平台」文字。
3. **登录页**（承接 ADR-045 左右分栏结构）：
   - 左上角：横向完整 logo `logo.svg`（高度 ~28px，含「蜂云时代」字标）
   - 中部大 logo：`favicon.svg` → `logo-icon.png`（~96px 蜂鸟图形）
   - 产品名 / slogan / 按钮等其余结构不变。
4. **favicon**：用蜂鸟图标生成 64×64 `favicon.png` 替换 `favicon.svg`，
   同步更新 `index.html` 的 `<link rel="icon">`。
5. **品牌绿不进入 UI 色板**：平台交互色保持主蓝 #1769D4 体系，蜂鸟绿色仅作为
   品牌图形出现（logo 本身是位图/SVG，颜色自带，不影响 CSS 变量）。

### Trade-off
- 选择**保留主蓝 UI + 绿色品牌图形**：全站 UI 规范零改动、改动面最小；
  代价是绿色 logo 与蓝色按钮并存，存在轻微的品牌色割裂。
- 选择 **PNG + SVG 双格式**（icon 用 PNG、完整 logo 用 SVG）：完整 logo 矢量
  缩放清晰；icon 用官方 PNG 保证与品牌方出图完全一致，代价是放大时略有栅格感
  （当前尺寸下不可感知）。

## Consequences
- 变容易：品牌一致性（顶栏/登录页/favicon 统一官方标识）。
- 变难：后续若品牌方换标，需同步替换 3 处静态文件（`public/brand/` + favicon）。
- 可逆性：**高**。纯静态资源 + 3 个文件的引用替换，无逻辑/接口/数据变化。

## 变更范围
- 新增：`frontend/public/brand/{logo-icon.png,logo-dark.png,logo.svg}`、
  `frontend/public/favicon.png`
- 修改：`frontend/index.html`、`frontend/src/layouts/MainLayout.vue`、
  `frontend/src/views/login/index.vue`
- 记录：`docs/frontend/changelog.md`
