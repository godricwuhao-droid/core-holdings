# ADR-036: 产品登记规则与表单重构（登记时间自动生成 / 产品有效期 / 参考区间自动同步 / 重复售卖规则）

## Status
Accepted（2026-10-22，业务需求：产品登记体验优化）

## Context
1. 「登记时间」要求人工选择，实际 99% 场景就是"今天"，且存在倒填。
2. 「长期买断」是财务术语，业务人员反馈不直观；语义是"产品有效期"。
3. 销售单价与参考价格区间各自手填，重复劳动且易填反（下限 > 上限）。
4. 重复售卖（`repeatSale`）：选择「卫星数据」类型时前端**自动勾选**（`create.vue:101`）；遥感数据容器因「数量单价」整卡隐藏（ADR-011）而**没有任何开关**，容器天然按明细售卖（不重复、剩余=未售明细数）却无 UI 表达；普通产品有开关但缺"取消勾选"的入口可见性。
5. 登记页表单为平铺长表单，字段归属不清晰。

## Decision
1. **登记时间**：新建不再提供输入（后端 `create_asset` 自动生成当天 `YYYY-MM-DD`）；编辑页只读展示；`inboundDate` 不再是入参必填（`PUT /assets` 若传值仍校验格式、允许改）。
2. **术语**：「长期买断」→「**产品有效期**」（checkbox 文案，语义不变：勾选 = 长期有效、无需到期时间；到期时间占位文案同步改）。
3. **参考区间自动同步**（仅新建登记页、仅非遥感容器）：填写「销售单价（元）」后自动写 `priceMin = salePrice`、`priceMax = round(salePrice × 1.02, 2)`；**用户手动改过某边界值（`touchedMin`/`touchedMax` 标记）后该边界即永久停止跟随**（以手改值为准；改回自动值也不会恢复跟随——实现口径，QA 确认与功能无异常）。编辑页不自动同步（存量区间口径保留）。
4. **重复售卖**：
   - 默认**不勾选**；移除「卫星数据自动勾选」逻辑（含卫星 Token/其他类型一律默认关）。
   - 遥感数据容器：**强制 `repeatSale=false`**（后端 create/update 若传 `true` → 400「遥感数据容器按明细售卖，不支持重复售卖」）；前端容器产品显示**禁用态开关 + 说明**「容器按可售明细售卖，剩余数量 = 未售明细数」。
   - 非容器产品保留开关（可开可关，取消勾选即生效——本次修复的"无取消入口"问题）。
5. **表单重构（仅 UI，不增不减字段）**：分块 = ①基本信息（板块/类型/名称/规格/主体；遥感容器在此块内展示"登记时间（只读）+ 有效期 + 重复售卖禁用态"）②数量与价格（非容器：单位/总数/单价/参考区间/重复售卖；容器整卡不显示）③附件与备注。全部沿用 §6 token 与 `.form-card/.form-grid/.info-bar`，不新增页面元素类型。

## Consequences
- **变容易**：登记操作从 8 步填空变 6 步；区间不再手算 +2%；容器语义在表单内可见。
- **变难**：「手改后不再跟随」需要前端记录区间是否被手改（`touchedMin/touchedMax` 标记），多一条状态分支；存量"卫星数据 auto=true"的产品**不受影响**（只改新建默认值，不回刷存量）。
- **可逆性**：高。回退 = 恢复常量/watch 与输入框；`inboundDate` 自动生成无数据迁移（旧值保留）。
