# ADR-054: 账号/用户管理三处增强——列表分页+过滤 / 自助改密 / 建号随机密码

## Status
Accepted（2026-11-04，已实现 + QA 独立回归全绿：① 账号列表客户端分页+过滤（关键字/角色/状态/组合、翻页/切条数、过滤回第 1 页、统计卡恒为全量）② 自助改密 POST /auth/change-password（全角色、校验旧密码 400、tokenVersion+1 旧 token 401 被踢、返回新 token 改后不掉线、<6 位 422、审计落痕、admin 重置他人不变）③ 建号随机密码（12 位去易混、三类各 1、明文可见、编辑无按钮、可登录）+ 顺带修 UserOut createdAt「创建时间」列，无新缺陷）

## Context
用户要求账号/用户管理域 3 处增强：
1. **账号管理列表**加**分页 + 查询过滤**。
2. **用户可自行修改密码**（非管理员也可）。
3. 管理员**创建账号时密码支持自动随机**。

现状（code-explorer 摸底）：
- `User`（`models.py` L345-361）：`username`/`passwordHash`（PBKDF2-SHA256 10 万轮 + 16B salt，标准库，`security.py` L172-186）/`name`/`role`（五角色，`security.py` L160）/`enabled`（布尔即状态）/`tokenVersion`/`createdAt`。**`tokenVersion` 机制：改密/改角色/禁用 +1 → 该用户所有旧 token 立即 401**（改密天然踢除其它登录态）。无 `mustChangePassword` 类字段。
- 账号管理 `/settings/users`（**仅 admin**，守卫 `router/index.ts` L203-206）→ `views/settings/users.vue`；双 tab「账号管理 + 审计日志」。账号 tab 6 列（L291-343）、**无分页无过滤**，`:data="users"`（全量）；**审计日志 tab 已有服务端分页 + 工具栏过滤（L357-403，现成范式）**。
- 接口（`api.py`）：`POST /auth/login`(L56)/`GET /auth/me`(L82)/`GET /users`(L90,全量,admin)/`POST /users`(L136,admin)/`PUT /users/{id}`(L154,admin,**含重置密码+tokenVersion+1**)/`DELETE /users/{id}`(L188,admin)。**无改密专用端点**（现状改密唯一通道 = admin `PUT /users/{id}` 带 password，不校验旧密码）。
- schema（`schemas.py`）：`UserOut`(L703-709，**不含 passwordHash、不含 createdAt**)、`UserCreate`(L712-716，无强度校验)、`UserUpdate`(L719-723)。
- 前端顶栏 `layouts/MainLayout.vue` L18-35：user-chip（姓名+角色 tag）**纯展示 span、无下拉** + 退出按钮。当前用户走 `auth.ts`（localStorage `token`+`currentUser`，`setSession`/`clearSession`/`setUser`，无 pinia）；axios 拦截器 401 清态跳登录。
- 建号/编辑共用弹窗 L409-457，密码框 L438-443（`dialog.form.password`）。
- **顺带 bug**：`UserOut` 不返回 `createdAt` → 表格「创建时间」列（L325-327）恒显示 `-`。

## Decision（含用户拍板）

| 项 | 决定 |
|---|---|
| **① 分页方式** | **客户端分页**（前端拿全量本地切片+过滤；`GET /users` **后端零改动**；统计卡基于全量照常算） |
| **① 过滤维度** | 关键字（`username`+`name` 模糊）+ 角色下拉（全部/五角色）+ 状态（全部/启用/禁用） |
| **② 改密校验** | **需输入并校验旧密码**（`verify_password`，错 → 400「旧密码不正确」） |
| **② 改密后登录** | **换发新 token、保持登录**（端点返回 `{token, user}`，前端 `setSession` 续用；其它设备/旧会话因 `tokenVersion+1` 被踢） |
| **② 改密端点** | 新增 `POST /api/auth/change-password`（`get_current_user`，**全角色**），body `{oldPassword, newPassword}`；`newPassword ≥ 6` 位 |
| **② 改密入口** | MainLayout 顶栏 user-chip → `el-dropdown`（修改密码 / 退出），**所有角色可见**（含 finance/viewer） |
| **③ 随机密码** | **12 位，大小写+数字，去易混（0/O/1/l/I）**，保证至少各含 1 个大写/小写/数字；`crypto.getRandomValues`；生成后**明文展示**于密码框（show-password 可切换）+ 可复制；**仅新建弹窗**可用 |
| **顺带修复** | `UserOut` 加 `createdAt: str`（`models` 已有字段）修「创建时间」列恒 `-`；确认/补建号时设 `createdAt`（老用户空则仍显 `-`，可接受） |
| **admin 重置他人** | 维持现状 `PUT /users/{id}` 带 password（不校验旧密码），不新增 |

### 接口契约
**`POST /api/auth/change-password`**
- 鉴权：`get_current_user`（全角色放行）。
- 请求体 `ChangePasswordInput { oldPassword: str, newPassword: str }`（`newPassword` `min_length=6`）。
- 校验：`verify_password(oldPassword, user.passwordHash)` 失败 → **400**「旧密码不正确」；`newPassword` <6 → **422**。
- 成功：`user.passwordHash = hash_password(newPassword)`、`user.tokenVersion += 1`，**返回 `{ token: <用新 tokenVersion 重编码的 JWT>, user: UserOut }`**（与 login 同形）；记 `record_audit`。
- **关键**：返回的 `token` 携带**新** tokenVersion，前端 `setSession` 后当前设备无缝续用；旧 token（旧 ver）全部 401。

**`UserOut`**：新增 `createdAt: str = ""`。
**`GET /users`**：**不变**（客户端分页）。

### 前端改动
1. `views/settings/users.vue` 账号 tab：
   - 工具栏（过滤）：关键字 `el-input` + 角色 `el-select` + 状态 `el-select`（仿审计 tab L357-371 的 `.toolbar`）。
   - `filteredUsers`（computed，按 keyword/role/enabled 过滤全量 `users`）+ `pagedUsers`（computed，按 `currentPage`/`pageSize` 切片）+ `el-pagination`（仿 L395-403）。
   - 表格 `:data` 改 `pagedUsers`；**统计卡（L72-76）仍基于全量 `users`**（total/启用/管理员数不变）。
   - 过滤变更 → `currentPage=1`；切页 → 表格刷新。
2. `views/settings/users.vue` 新建弹窗：密码框（L438-443）加「随机生成」按钮（suffix/append）→ 填 `dialog.form.password`；**仅新建**显示（编辑弹窗密码框"留空不改"，不显随机按钮）。
3. `layouts/MainLayout.vue`：user-chip（L23-33）→ `el-dropdown`（项：修改密码 / 退出登录），**所有角色可见**；「修改密码」→ 改密弹窗（旧密码 / 新密码 / 确认新密码，前端校验 新=确认、≥6）→ `changeMyPassword(old,new)` → 成功用**返回的新 token** `setSession`（**关键：更新 localStorage token，否则下次请求 401**）+ 同步 `currentUser` → 关闭 + toast「密码已修改」。
4. `api/index.ts`：加 `changeMyPassword(oldPassword, newPassword)` → `POST /auth/change-password`（返回 `{token, user}`）；`listUsers()` 不变。
5. 随机密码生成器（前端小 util）：`crypto.getRandomValues`，字符集去易混（大写去 O/I、小写去 l、数字去 0/1），12 位，保证至少各含 1 个大写/小写/数字后洗牌。

## Consequences
**变容易**：账号可自助改密（不必找 admin）；建号一键随机密码；账号列表可搜/可筛/可翻页。

**变难 / 风险**：
- **改密换 token（关键正确性点）**：前端必须在响应后 `setSession(新token)`，否则下次请求用旧 token 会 401 掉线。
- **客户端分页**：用户量增大（上千）时全量拉取会变重——可日后升级服务端分页（审计 tab 已有服务端范式，预留路径）。
- 顶栏 user-chip 改 `el-dropdown`：影响**所有页面/所有角色**，需确保不破坏现有退出、finance 路由收窄、五角色可见性。
- 顺带 createdAt：老用户空则仍显 `-`（可接受）；新号应设值。

**可逆性**：高——前端 UI + 1 个新增端点 + `UserOut` 加字段，**无破坏性迁移**。

## 任务拆分
- **backend-dev**：新增 `POST /auth/change-password`（schema `ChangePasswordInput` + 旧密码校验 + `tokenVersion+1` + 返回新 token/user + 审计）+ `UserOut` 加 `createdAt` + 确认/补建号设 `createdAt`。自测：旧密码错 400 / 对 200 返回新 token / 新 token 可用 / 旧 token 401 / newPassword<6 422 / UserOut 含 createdAt / 非 admin 角色可改自己密码。
- **frontend-dev**：users.vue 客户端分页+过滤 + 随机密码按钮 + MainLayout 顶栏 dropdown+改密弹窗 + api `changeMyPassword` + 随机生成器。`vue-tsc` 0。
- **QA**：三处 + 护栏（改密跨角色/换 token 续用/旧 token 踢除、admin 重置他人不变、建号/随机、登录/登出、五角色可见性、finance 顶栏可达、账号列表过滤分页 + 统计卡不变）。
