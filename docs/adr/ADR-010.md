# ADR-010: 卫星板块新增"遥感数据"资产类型（省/精度/日期三维唯一模型）

## Status
Superseded by ADR-011（2026-10-16 被取代：改为"父资产 + 可售明细"两层模型；本 ADR 的三维字段直接挂 assets 的设计废弃，已建演示资产删除）

## Context
卫星服务板块现有二级类型：卫星 Token / 卫星数据。需新增第三种：**遥感数据**。
遥感卫星数据的售卖粒度特殊：**省（可含市）× 精度 × 影像日期** 三个维度组合唯一确定一个售卖资产（如"河北省石家庄市 1.5m 2026-09-15"、"甘肃省 1m 2026-08-01"）。

## Decision
1. **不建独立表，扩展统一 Asset 模型**：`assets` 表新增 4 个可空列（幂等迁移）：
   | 列 | 类型 | 说明 |
   |---|---|---|
   | `province` | VARCHAR(64) NULL | 省/自治区/直辖市，如"河北省" |
   | `city` | VARCHAR(64) NULL（默认 `''`） | 市，可空（省级资产不填），如"石家庄市" |
   | `resolution` | FLOAT NULL | 精度，单位**米**（1.5 / 1.0），展示 `1.5m` |
   | `imageDate` | VARCHAR(10) NULL（默认 `''`） | 影像日期 `YYYY-MM-DD` |
   仅 `type === '遥感数据'` 资产使用，其余类型恒为空。前端 `Asset` 接口同步加 4 个可选字段（camelCase 对齐）。
2. **唯一性约束（后端权威）**：`create_asset` 对遥感数据校验 `(province, city, resolution, imageDate)` 组合不重复，重复返回 400「已存在相同 省/市 + 精度 + 日期 的遥感数据资产」。前端表单失焦/提交前同步预校验并提示。
3. **业务属性默认值**：`quantity = 1`，`unit = '份（区域·精度·日期）'`，`repeatSale = true`（影像数据默认可重复售卖、只计次不扣量，与卫星数据口径一致；允许关闭）。计价走标准 `'unit'` 模式（1 份 = 1 个包，单价即整数元售价，无循环小数问题）。
4. **名称自动生成**：新建表单按 `省 + 市 + 精度 + 日期` 自动拼名称（如"河北省石家庄市 1.5m 2026-09-15"），随三维字段实时联动，可人工修改。
5. **列表与展示**：
   - `constants.ts` CATEGORY_UNITS 卫星板块增加 `{ board: 'satellite', type: '遥感数据', unit: '份（区域·精度·日期）', note: '按 省/精度/日期 三维唯一售卖' }`；
   - 资产列表卫星板块二级页签由「全部 / 卫星 Token / 卫星数据」扩为「全部 / 卫星 Token / 卫星数据 / 遥感数据」；
   - 资产详情"基本信息"页签对遥感数据追加展示 省/市、精度、影像日期（非遥感类型不显示）。

## Consequences
- 变容易：完全复用现有资产列表/详情/购物车/下单/交付全链路，无新流程；三维唯一性在入库时即防止重复建资产。
- 变难：Asset 模型出现类型专属可空字段（`province/city/resolution/imageDate`），后续若出现更多类型专属字段需警惕 Asset 膨胀（约定：≤3 个类型专属字段组内可接受，超出再拆子表）；列表/详情/表单/类型字典 4 处需同步维护。
- 可逆性：**高**——仅加可空列与类型分支，删除类型选项并忽略 4 列即回退，不影响存量其他类型资产。
