# ADR-053: 产品域——税点属性 + 去「售卖数量」列 + 销售单价改采购单价 / 自动参考区间

## Status
Accepted（2026-11-04，已实现 + QA 独立回归全绿：税点展示/录入/越界/财务可见 + 去售卖数量列（重复售卖 tag 保留）+ 销售单价改采购价对外不展示/列表详情抽屉显区间下限 + 填采购价自动 ×1.01/×1.02 区间（新建+编辑、手改不覆盖、容器排除）+ 可售金额切 priceMin + ADR-052 双向区间仍生效，无新缺陷）

## Context
用户对产品域（产品及服务）提出三处改动：
1. **税点**：产品新增「税点」属性，在产品及服务列表表头展示，登记产品（新建/编辑）中支持录入。
2. **去售卖列**：产品及服务列表去掉「售卖」字段展示 → 拍板为「**售卖数量**」独立列（`shippedQty`）。
3. **销售单价→采购单价**：原「销售单价」字段改为「**采购单价**」（内部成本，对外不展示、仅编辑表单可见）；列表/详情/抽屉原本展示销售单价的位置改为展示「**参考区间下限 `priceMin`**」；填入采购单价后**自动按 1%~2% 生成参考区间**。

现状（code-explorer 摸底）：
- `Asset.salePrice`（`Float` 非空=0）、`priceMin`/`priceMax`（`Float` nullable，ADR-018 参考区间）、`repeatSale`（Boolean）、`pricingMode`（unit/amount）。**全仓无税点字段**。
- 产品列表 `frontend/src/views/assets/list.vue`（4 板块共用；算力 `compute.vue` 独立页、无单价/售卖列）：「售卖数量」列 L477-482（`shippedQty`）、「销售单价」列 L483-485（`salePriceText` L260-267）。
- 登记表单 `frontend/src/views/assets/create.vue`（新建/编辑复用）：`销售单价（元）`输入 L351-355（`form.salePrice`）、参考区间输入 L361-370（`form.priceMin/priceMax`）；已有"新建时单价→区间自动同步"watch L124-131（现公式 min=单价、max=×1.02，仅新建）。
- 详情页 `frontend/src/views/assets/detail.vue` L1054-1060 展示销售单价；快览抽屉 list.vue L596-605 同口径。
- 前端 `types.ts` `availableValue`（L222-225）= 可售数量 × `salePrice`（"可售金额"看板/板块统计）。
- 后端 `schemas.py` `AssetOut/AssetInput/AssetUpdate` 已含 salePrice/priceMin/priceMax；`services.py` `ASSET_FIELD_LABELS` L688 `"salePrice":"销售单价"`。

## Decision（含用户拍板）

### 拍板口径
| 项 | 决定 |
|---|---|
| **区间公式** | `priceMin = 采购价 × 1.01`，`priceMax = 采购价 × 1.02`（`roundAmount` 6 位小数规整） |
| **生成时机** | **新建 + 编辑都生效**：用户**改动采购价**即按公式重算区间；**用户手动改过区间（touchedMin/Max）则不覆盖**；**编辑模式初始加载不触发**（仅用户实际改动采购价才重算）。范围 = **非遥感容器**产品（容器用明细价，排除，与现状一致） |
| **税点** | **整数百分比**（存 `13` = 13%），**纯展示元数据**，**不参与任何金额计算**；`Asset` 层字段，**nullable**（`None` = 未设置 → 展示 `-`） |
| **售卖列** | 删「**售卖数量**」独立列（`shippedQty`）；「重复售卖」tag（`repeatSale`，在可用数量列内）**保留** |
| **salePrice 列** | **复用原列**（**无 DB 迁移**），仅语义/文案改为采购单价；**不重命名** `purchasePrice`（避免波及 38 个文件计价引用） |
| **计价/统计** | 前端 `availableValue`（"可售金额"统计）改用 `priceMin`（兜底 `salePrice`→0），与列表展示口径一致（对外卖价，不混入成本） |
| **自动区间实现位置** | **前端**（create.vue watch，扩展编辑模式）；**后端不自动算区间**（保持纯存储语义，避免覆盖用户手填值） |

### 字段规格
- **新增 `Asset.taxPoint`**：`Mapped[int | None]`（`Integer`，nullable，default `None`），语义"税点百分比整数"（`13` = 13%）。
- **`salePrice`**：字段名/类型不变，**语义改为采购单价**（内部成本）。
- **`priceMin`/`priceMax`**：不变（参考区间），由前端自动区间填充。

### 展示口径（采购价"对外不展示，仅编辑可见"）
- **列表**「销售单价」列 → 展示 `priceMin`（`isRemoteContainer` 或 `priceMin==null` 显示 `-`；否则 `formatMoney(priceMin)` + 单位后缀 + 保留「参考区间 min~max」追加）。
- **详情**「销售单价」只读项（detail.vue L1054-1060）→ 同样改展示 `priceMin`/区间（**不再对外展示采购价**）。
- **快览抽屉**（list.vue L596-605）→ 同列表口径展示 `priceMin`。
- **购物车**：销售单价列已在 ADR-052 删除，无影响。
- **登记表单**（create.vue 新建+编辑）→ 采购单价输入框可见（`form.salePrice`，label 改「采购单价（元）」）。
- **税点**：列表新列（`taxPoint`，`null`→`-`，否则 `{n}%`）；详情展示（`null`→`-`）；表单录入（整数输入）。

### 后端改动
1. `models.py` `Asset`：加 `taxPoint: Mapped[int | None]`（`Integer` nullable，default None）。
2. `main.py` `_ensure_migration()`：幂等 `ALTER TABLE assets ADD COLUMN taxPoint INTEGER`（参照 L202-203 priceMin/priceMax 加列写法）。
3. `schemas.py`：`AssetOut`/`AssetInput`/`AssetUpdate` 各加 `taxPoint: int | None = Field(default=None, ge=0, le=100)`。
4. `services.py` `ASSET_FIELD_LABELS`：`"salePrice": "销售单价"` → `"采购单价"`；新增 `"taxPoint": "税点"`（编辑日志中文映射）。
5. **后端不做自动区间计算**（保持 create/update 现有存储 + `_validate_price_range` min≤max 校验）。

### 前端改动
1. `list.vue`：删「售卖数量」列（L477-482）；「销售单价」列 `salePriceText` 改读 `priceMin`（L260-267 + L483-485）；新增「税点」列（`taxPoint`，null→`-`）；快览抽屉销售单价（L596-605）同改 `priceMin`。
2. `create.vue`：`销售单价（元）` label → `采购单价（元）`（+ 卡片 hint L336）；新增税点输入（整数，0-100，可选）；自动区间 watch（L124-131）**公式改 ×1.01/×1.02** + **扩展编辑模式**（初始加载不触发、手改区间不覆盖、仅非容器）。
3. `detail.vue`：L1054-1060 销售单价展示改 `priceMin`/区间（去采购价对外展示）；加税点展示（null→`-`）。
4. `types.ts`：`availableValue`（L222-225）改 `q * (a.priceMin ?? a.salePrice ?? 0)`（unit 模式；amount 模式仍返 0）。

## Consequences
**变容易**：对外只暴露参考区间（卖价），成本（采购价）内部化；税点可登记/可展示；列表卖价口径统一为区间下限。

**变难 / 风险**：
- **`salePrice` 语义漂移**：38 文件引用它，但**计价逻辑不变**（仍按 `salePrice` 值算，值语义从"销售价"变"采购价"）。"可售金额"统计已切 `priceMin`，避免成本混入卖价统计。
- **存量数据**：现有 `salePrice`（原销售价）直接变"采购价"语义——**值保留、语义由业务接受**（无迁移）。存量**无参考区间**的产品：列表销售单价列显示 `-`（直到补区间/重算）。
- **税点 nullable**：前端所有展示点必须兜底 `null` → `-`。
- **自动区间编辑模式**：需正确区分"初始加载"与"用户改动"，避免编辑页一打开就覆盖已存区间。

**可逆性**：高——前端展示调整 + 1 个可空新列 + 表单 watch 逻辑，**无破坏性迁移**（`salePrice` 列未改名）。

## 接口契约（前后端）
| 项 | 契约 |
|---|---|
| 新字段 | `taxPoint: int | None`（`ge=0, le=100`）加入 `AssetOut` / `AssetInput`（POST /assets）/ `AssetUpdate`（PUT /assets/{id}，传 null 清空） |
| 采购价 | = `salePrice`（字段名不变，语义=采购单价） |
| 参考区间 | `priceMin`/`priceMax`（不变）；**自动生成是前端行为**，接口层不感知 |
| 列表/详情/bootstrap | 返回体**已含** salePrice/priceMin/priceMax，前端展示 priceMin **无需后端改接口**；`taxPoint` 需后端 schema+模型+迁移后一并返回 |
| 校验 | 后端 `_validate_price_range` 仍校验 min≤max；税点 `0≤n≤100` |

## 任务拆分
- **backend-dev**：models 加列 + main 幂等迁移 + schemas 三处 + ASSET_FIELD_LABELS 文案（salePrice→采购单价、加 taxPoint）。自测：建/改带 taxPoint 的产品、返回体含 taxPoint、存量产品 taxPoint=null、区间校验不变。
- **frontend-dev**：list（删售卖数量列 + 销售单价→priceMin + 加税点列 + 抽屉）+ create（采购单价 label + 税点输入 + 自动区间公式/编辑模式）+ detail（销售单价→priceMin + 税点展示）+ types（availableValue→priceMin）。`vue-tsc` 0。
- **QA**：三处独立回归 + 护栏（下单/区间双向 ADR-052、计价/可售金额、存量产品、税点展示兜底、5 板块）。
