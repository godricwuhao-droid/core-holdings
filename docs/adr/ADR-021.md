# ADR-021: 遥感售卖明细（rs_items）参考价区间

## Status
Accepted（2026-10-20，业务确认：售卖明细编辑弹窗应有参考区间——取代 ADR-018 §5「遥感行未设区间即不限制」的推断口径）

## Context
ADR-018 引入了产品级参考区间（assets.priceMin/priceMax）用于生态下单折扣校验，并允许遥感明细行（rs_items，省×精度×月份）在下单时输入折扣金额。但 ADR-018 §5 当时假设"遥感行未设区间即不限制"——即遥感明细行实际上**没有任何区间约束**，折扣金额可为任意正数。业务确认该假设不成立：遥感明细与产品一样应有参考价区间，作为折扣校验与展示依据。容器（type='遥感数据' 父产品）无定价（salePrice=0、价格卡隐藏），区间不能挂在容器上。

## Decision
1. `rs_items` 新增 `priceMin` / `priceMax`（Float nullable，元/份，选填），明细新增/编辑弹窗可录入；校验与产品区间同口径：只填其一允许（单边边界），两者都有时 min ≤ max 否则 400。
2. **折扣校验口径**：生态下单（购物车行更新/checkout/sales/order）中遥感明细行（itemId 非空）的金额校验，改用**该 rs_item 自身的 priceMin/priceMax**（不再取父产品容器的区间）；普通产品行仍用 assets 区间；未设区间 = 不限制（同 ADR-018）。
3. 原价快照（ADR-018 §2）不变：遥感行 origPrice/origAmount 仍 = 该明细 price 快照。
4. 展示：明细列表/编辑弹窗展示参考区间（有值时 `¥{price}（参考区间 {min}~{max}）`）；购物车遥感行的区间提示改读该行 rs_item 的区间。
5. 存量明细（含 2026-10-20 批量录入的 96 条）区间为 NULL = 不限制；是否补录区间属业务操作，不在本 ADR 范围。

## Consequences
- 变容易：遥感折扣金额有了与产品一致的校验边界；明细粒度区间比容器级更精确（同产品不同省/月份价格差异大）。
- 变难：校验函数 `_check_discount_range` 需区分行类型取不同区间来源；明细编辑接口入参扩大。
- 可逆性：高。可空新列 + 校验分支，revert 即恢复"不限制"行为。
