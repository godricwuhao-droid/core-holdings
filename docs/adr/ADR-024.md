# ADR-024: 交付物模板彻底下线 + 交付物附件（单文件）

## Status
Accepted（2026-10-21，业务要求：交付物全部在产品详情页手动维护；每项交付物挂单个附件，抽屉与详情页两处可预览）

## Context
1. 交付物当前是「设置页模板 → 产品实例惰性自动生成」模式：`/settings/deliverables` 维护按产品类型的模板，bootstrap 时对产品批量补生成实例。业务不再需要模板抽象——模板是内部预设口径，实际交付物因产品而异，一律手动登记更有价值。
2. 交付物实例只有文字字段（name/category/version/meta/status），无法承载实际交付文件；产品清单（contractFile）已验证「上传→预览→下载」链路可行（/upload 白名单已含 jpg/png/pdf/docx，FilePreview 组件已支持图片/PDF/docx 预览）。
3. 抽屉「最近动态」区块（日志+流水合并时间线）业务价值低，占用抽屉纵向空间，且详情/流水页签已有完整数据。

## Decision
1. **交付物模板彻底下线**（用户拍板）：
   - 后端：删 `deliverable_templates` 表与模型/schema/种子数据；删 3 个 `/deliverable-templates` 端点；删 `_init_asset_deliverables` 及全部调用点（bootstrap 惰性初始化、`add_asset_deliverable` 内首增触发）；bootstrap 不再返回 `deliverableTemplates`。
   - 前端：删 `views/settings/deliverables.vue`、路由、`MainLayout` 菜单项（「基础设置」子菜单保留，仅剩「账号与审计」）；`api/index.ts` 删模板 CRUD 函数与镜像字段；`types.ts` 删 `DeliverableTemplateItem`。
   - 交付物实例完全手动添加（详情页「交付物」页签已有新增入口，保留）。
2. **存量实例清空重来**（用户拍板）：一次性幂等迁移清空 `asset_deliverables` 全表（含手动补充项，各产品从零添加）。执行方式照抄 `main.py` `_ensure_migration` 模式（删前 assert 表存在；无引用风险——实例不被其他表引用）。
3. **交付物附件：每项单个文件**（用户拍板）：
   - 新列 `asset_deliverables.file`（String，存 upload 返回的散列文件名；空/NULL=无附件）。
   - `PUT /assets/{id}/deliverables/{item_id}` patch 白名单追加 `file`（空串或 null → 清空附件）；bootstrap `assetDeliverables` 携带 `file`。
   - 上传复用通用 `POST /upload`（不改后端白名单/大小限制）；**交付物前端 accept 更严**：仅 `.pdf,.docx,.png,.jpg,.jpeg,.gif,.webp`（禁 .doc 旧版、禁 .xlsx，前端 upload 前校验扩展名，不符 toast 拦截）。
   - `DELETE /api/upload/{filename}` 引用检查追加 `asset_deliverables.file`。
   - 交互与「产品清单」(contractFile) 一致：上传/替换（重传覆盖）/删除（置空，同步删物理文件）/预览。
4. **预览两处入口**（用户要求）：
   - 详情页「交付物」页签：行内附件名点击 → 预览弹窗（复用 `FilePreview`）；
   - 产品列表抽屉「交付物」区块：附件名点击 → 同一预览弹窗；
   - 预览能力随 FilePreview 现状：图片/PDF 在线、docx 转 HTML、（.doc 已被禁）；弹窗内保留下载入口。viewer 只读可见预览，上传/删除仅 editor/admin（受 require_editor 天然约束，前端按 canWrite 隐藏写入口）。
5. **抽屉删「最近动态」区块**（用户要求）：删模板区块 + `dActivities`/`loadDrawerActivities` 脚本 + 相关样式；`dProjects` 若仅此处使用一并清理。

## Consequences
- 变容易：交付物单一维护入口（详情页）；模板/实例两层概念消失，代码与心智模型减一层；交付物可挂实际文件，抽屉/详情即可验收查看。
- 变难：存量交付物实例全部清空（用户已确认）；「基础设置」子菜单只剩一项（菜单结构略显空，可接受）；交付物附件的 upload 删除引用检查多一条。
- 可逆性：**中**。附件列与预览为纯增量、可逆性高；但模板表删除 + 存量实例清空为破坏性操作，revert 需从 .db.bak 恢复（后端目录下有备份）。
