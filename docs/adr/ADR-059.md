# ADR-059: 审核订单页 review.vue 优化（点击即改 + 服务期限拆两列 + 删说明条）

## Status
Accepted（2026-11-10，已实现 + 自测/Architect 代码核对通过：新增 `components/ClickEditNumber.vue`——常态数值文本(slot)+hover 主蓝提示、点击就地 `el-input-number`(复用 amountInputFormatter/Parser)、失焦/回车提交、Esc 还原、**收拢且 `draft!==modelValue` 才 emit**(守"只传变更")、模块级单编辑态；① 删 `.info-bar rv-rules` 4 行；② 数量(min1/precision0)/实际单价(unit)/销售金额(非unit) 三处 `v-model` 仍绑 `l.qty/l.price/l.amount`，派生/`-`/rs 格静态；③ 服务期限拆「开始时间/结束时间」两列各 150px 绑 serviceStart/End、rs 两列 `-`；review.vue script 区仅 +1 行 import，计算链/只传变更/派生/校验零改动；自测含 F12 只传变更 payload + EP 2.14 el-input-number 无 Enter 的 keydown 兜底，vue-tsc 0）

## Context
ADR-057 改版后的审核订单页（`review.vue`）仍偏"表单感"：① 顶部有一段 4 行 `.info-bar` 操作说明，用户希望删除以精简；② 「实际单价 / 销售金额 / 数量」是**常驻** `el-input-number` 输入框，行内一片输入框显得杂乱，用户希望"**直接在金额值上点击修改，无需单独的修改框**"；③ 「服务期限」把开始/结束两个日期塞在一个表头列里（开始 ~ 结束），用户希望拆成**两个表头列**（开始时间 / 结束时间）。

## Decision
1. **删说明条**：删除 `review.vue` 顶部 `.info-bar`（可调整项 / 只作用于勾选 / 终审价不回写 / 合同总价留空=明细合计，4 行）。其中"合同总价留空=明细合计"仍由合同头 tooltip 覆盖、"服务期限成对填写"仍由列头 tooltip 覆盖，不额外补位。
2. **点击即改（保留 6 列）**：把「实际单价(unit 行) / 销售金额(amount·rs 行) / 数量(非 rs 行)」的常驻输入框改为**点击即改**——常态显示为数值（金额走既有 `formatMoney` ¥+千分位、数量走整数+单位），点击该值才出现输入框（复用既有 `el-input-number` + `amountInputFormatter/Parser` / min / precision），**失焦或回车提交、Esc 取消**；hover 有轻微可编辑提示（遵循 `core-holdings-ui`）。**派生/不适用单元格保持静态不可点**：unit 行销售金额=派生只读（+副区"参考单价≈"）、amount/rs 行实际单价=`-`、rs 行数量=1。
3. **服务期限拆两列**：单一「服务期限」列拆为「**开始时间**」「**结束时间**」两个表头列，各自 `el-date-picker`（分别绑 `l.serviceStart` / `l.serviceEnd`）；rs 行两列均显 `-`；列头 tooltip（成对填写说明）保留。
- **硬约束（关键）**：以上**纯展示层**改动——所有编辑仍写入同一响应式字段 `l.price / l.qty / l.amount / l.serviceStart / l.serviceEnd`，**ADR-050/057 下游逻辑零改动**：`lineAmount → contractTotal → checkedTotal` 计算链、合同总价权威 + 按明细比例分摊、**只传变更项**（`targetLines`/`contractsPayload`）、行级变更检测（`orig*`）、校验范围=勾选、派生与锁定/遥感回退，全部保持不变。

## Consequences
- 易：表格更干净（输入框不再常开）、列语义更清晰（开始/结束独立）、信息条精简；交互一致（金额/数量同一点击即改范式）。
- 难/代价：新增一个点击即改交互态（focus/blur/enter/esc、编辑中切行、校验失败回显）；需保证提交值与 v-model 字段**严格一致**，否则破坏"只传变更"。
- 未选方案：价格编辑并入"销售金额"列去掉"实际单价"列（用户已选**保留 6 列**）；服务期限保持单列（用户要求拆两列）。
- 可逆性：**高**（纯前端展示层，无 schema/后端改动，无数据迁移）。
