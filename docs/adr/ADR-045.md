# ADR-045: 登录页 UI 重构为左右分栏布局

## Status
Accepted

## Context
现有登录页为单张 400px 居中卡片，视觉单薄，无品牌展示。产品方要求参考
Interface AI（jiekou.ai）登录页风格进行优化：左右分栏、左侧品牌展示区、
右侧带 label 的规范表单、全宽圆角登录按钮。

参考页要点：左区（~50%）白底品牌区（顶部 logo+名称、中部大标题+slogan+描述、
底部装饰）；右区 ~400px 表单列（标题+品牌名蓝色高亮、label 式字段、全宽大圆角
按钮、底部引导文案）。

## Decision
1. **布局**：≥1024px 左右分栏（左品牌区 + 右表单区）；<1024px 回退现有居中卡片
   （保证窄屏/移动端可用）。
2. **左侧品牌区**：顶部小 logo（复用 `public/favicon.svg`）+「蜂云产品及服务平台」；
   中部大号 logo + 32~36px 产品名 + slogan「产品及服务一体化协同平台」+ 一句能力
   描述（覆盖资产管理、销售项目、交付与出入库协同）；底部浅蓝 CSS 装饰
   （渐变/网格，纯 CSS 实现，不引入图片资源）。
3. **右侧表单区**：「欢迎登录 **蜂云产品及服务平台**」（品牌名主蓝高亮）+ 副标题；
   label 式表单（*用户名 / *密码），输入框 border #D8E1EC、圆角 10px、高度 44px；
   登录按钮全宽、高度 44px、圆角 10px、品牌主蓝 #1769D4（hover/active 同色深阶）。
4. **不新增「忘记密码 / 注册」入口**：后端未提供对应能力，遵循 non-mock 原则。
5. **功能逻辑零改动**：`login()` / `setSession()` / `refresh(true)` /
   `route.query.redirect` 回跳、错误提示（后端中文 detail）逻辑原样保留。

### Trade-off
- 选择了**品牌主蓝按钮**而非参考页的纯黑按钮：与全站 UI 规范（#1769D4 主色）
  一致；放弃的是参考页的视觉冲击力。
- 选择了**纯 CSS 装饰**而非产品截图：无需新增设计资源、零维护成本；放弃的是
  参考页底部产品图的真实感。
- 选择了**窄屏回退卡片**：不额外开发响应式双态品牌区；代价是窄屏下品牌展示弱化。

## Consequences
- 变容易：登录页品牌感与产品定位传达；后续换品牌素材只需改左区。
- 变难：`index.vue` 样式量增加（新增分栏/装饰/窄屏回退三套样式），需按断点
  维护；logo 从 inline icon 改为 `<img src="/favicon.svg">`，若日后更换 logo
  文件需同步登录页。
- 可逆性：**高**。纯前端单文件视觉改动（`src/views/login/index.vue`），无数据、
  无接口、无路由变化，可随时回滚到居中卡片版本。

## 变更范围
- 修改：`frontend/src/views/login/index.vue`（模板 + 样式，script 逻辑不动）
- 记录：`docs/frontend/changelog.md`

## 修订（2026-10-23）
决策 3 中「底部浅蓝 CSS 装饰」被产品方质疑无信息量，修订为：**左区底部改为
3 张轻量能力卡（资产管理 / 销售管理 / 交付协同，EP 图标 + 一句话说明，纯 CSS
实现，主蓝色板）**，替换原 `::before` 渐变块 + `::after` 网格装饰。其余决策不变。
