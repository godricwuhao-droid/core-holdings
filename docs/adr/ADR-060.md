# ADR-060: 审核订单页 review.vue 合同头字段点击即改 + 合同头字号调大

## Status
Accepted（2026-11-10，已实现 + 自测/Architect 代码核对通过：新增 `components/ClickEditText.vue`（文本版，交互与 ClickEditNumber 一致：常态 slot 文本+hover 提示、点击出 el-input maxlength128+聚焦、失焦/回车提交 trim、Esc 还原、模块级单编辑态、**trim 后仅值变才 emit**）；① 客户名 `el-input`→`ClickEditText`（空显 `--warning-color` 弱警示、`:deep(.cet-view)` 14px/600、提交写回 customer，"客户名空→确认被拦"不回归）、合同总价 `el-input-number`→复用 `ClickEditNumber`（空显"留空=明细合计"、提交写回 amount，总额权威→小计联动）、小计 `.rv-ct-subtotal-val` 仍只读 `contractTotal`；② `.rv-lbl` 12→13px、客户名 14px/600、小计金额维持 16px/700；合同级只传变更/确认校验/计算链零改动（`setContractField`/`contractsPayload`/`contractInvalid` 原样）；自测含 F12 双字段只传变更 + 空客户名拦确认 + 字号 computed 实测 + ADR-059 明细表点击即改回归，vue-tsc 0）

## Context
ADR-059 把审核页**明细表**里的价格/数量/金额改成了"点击即改"（`ClickEditNumber`），但**合同头**（每张明细表上方那行）的「**客户名称**」「**合同总价**」仍是**常驻输入框**，观感不一致；且合同头那行多数标签是 12px 小字，不够醒目。用户要求：这两个输入框同样改"点击内容即编辑"，并把合同头那行的字体调大。

## Decision
1. **合同头两字段改点击即改**（对齐 ADR-059 范式）：
   - **客户名称**（`.rv-ct-customer-input`，`el-input` 文本，绑 `customer`）→ 点击即改：**常态显示客户名**（空则显示弱提示文案 + 可编辑态提示），点击出 `el-input`（`maxlength=128`、trim），**失焦/回车提交、Esc 还原**；提交写回 `customer`（沿用 `setContractField(c.id,'customer',v)`），既有"**客户名空 → 确认被拦**"校验不回归。
   - **合同总价**（`.rv-ct-amount-input`，`el-input-number` 数值，绑 `amount`）→ **复用 `ClickEditNumber`**：常态显示所填总价（`amount!=null` 显 `formatMoney(amount)`；`amount==null` 显弱提示"留空 = 明细合计"），点击出 `el-input-number`（`:min=0` + `amountInputFormatter/Parser`），失焦/回车提交、Esc 还原；提交写回 `amount`（`setContractField(c.id,'amount',v)`）。
   - **小计**（`.rv-ct-subtotal-val`，显 `contractTotal(c.id)` 有效总额）**保持只读**，不受影响。
   - **文本型点击即改**：新建 `ClickEditText.vue`（或给组件加 `type` 支持文本），交互与 `ClickEditNumber` 完全一致（常态文本 + hover 提示、点击出框聚焦、失焦/回车提交、Esc 还原、模块级单编辑态、**仅值变化才 emit**）。
2. **合同头字号调大**：`.rv-ct-head` 那行（客户名 / 主体 tag / 「合同总价（元）」标签 / 小计标签）由 12px 小字调大——客户名 ~14px/600、标签 ~13px、**小计金额维持 16px/700**、主体 tag 保持或微调；让合同头更醒目且层次清晰（遵循 `core-holdings-ui`）。

## Consequences
- 易：合同头与明细表交互统一（都是点击即改）、合同头更醒目；纯展示层。
- 难/代价：新增文本型点击即改（`el-input` 的 focus/blur/enter/esc/maxlength/trim）；需保证客户名/总价提交仍写回**原字段**，"只传变更"（合同级 `amount`/`customer` 变更检测）与确认校验不回归。
- 可逆性：**高**（纯前端展示层，无 schema/后端改动）。
